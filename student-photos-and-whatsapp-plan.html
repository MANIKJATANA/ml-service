2

Student "Appears in" — smart event filter

Abhi har event ka ek raw chip dikhta hai. 10–20 events pe ye bekaar ho jaayega. Naya filter: All + latest 3 events quick chips + ek "Filter events" picker (search waala) baaki sab ke liye.

…/students/aarav

Appears in

Quick chips + poore itihaas ke liye picker button.

All · 28 Sports Day · Aug 20 Annual Fn · Jul 12 Trip · Jun 3 🔍 Filter events ▾

Behaviour

  • All → student ki saari effective photos (har photo pe "Event · Date" caption). Default = All.
  • Latest 3 chips → date ke hisaab se sabse naye 3 events (kitne dikhaye — tunable, abhi 3).
  • Filter events ▾ → searchable popover (existing StudentPicker pattern reuse → EventPicker) — poori list, count+date ke saath. Koi bhi event chuno → grid us event pe.
  • Selected event → sirf us event ki photos (useStudentMedia); All → sab (useAllStudentMedia). Dono hooks pehle se hain.

✅ Pure frontend — koi backend/API change nahi.

3

Send ko divide — select-all / random select

Abhi "Send on WhatsApp" seedha saari photos bhejta hai. Ise choice do: current event ki sab select karo, ya random N select karo, ya photos tap karke khud chuno — phir selected count bhejo/download karo.

…/students/aarav — Sports Day
☑ Select all (28) 🎲 Select random Clear 3 selected
Send 3 on WhatsApp ⤓ Download 3

Behaviour

  • Tap-to-select — grid pe selection mode on (existing PhotoGrid selectionMode reuse).
  • Select all (this view) — jo bhi abhi dikh raha (current event, ya All) uski sab photos.
  • Select random N — current view se N random photos (client-side shuffle; default 10, tunable).
  • Send N → confirm dialog exact count + cost dikhaata hai → sendWhatsApp(studentId, selectedIds). Subset send pehle se supported (server effective-set se intersect karta hai — safe).
  • Download N → same selection useDownloadAll pe (zip).
  • Kuch select nahi → Send/Download disabled (ya "sab bhejo" ka clear default).

✅ Pure frontend — send endpoint already media_ids subset leta hai; koi backend change nahi.

Honest limits / scope
  • Random select client-side hai (jo photos load hui hain unme se) — abhi tak masonry/window sab load kar leta hai student scale pe, thik hai.
  • Phase 2/3 sirf student-detail "Appears in" pe. Event-gallery ke "By student" tab pe same treatment ek easy follow-on hai (abhi scope se bahar, focused rakhne ke liye).
  • Platform-only me "enabled" = token+sender+template set (alag global on/off toggle chahiye to 1-line add ho jaayega).
  • Real (non-interim) delivery abhi bhi tere Meta setup pe depend — verified number + approved template + non-expiring token.
