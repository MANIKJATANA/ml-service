WhatsApp

Platform-wide WhatsApp settings — sender number, Meta access token, aur interim test number. Sab DB me, yahin editable (no restart).

Meta ka phone-number ID (Meta → WhatsApp → API Setup se — numeric "Phone number ID", +91… wala number nahi). Sirf DB me store hota hai — yahi ek jagah set hota hai (koi .env nahi).
A token is set (ending 1234). Blank chhod = purana rahega; naya paste = replace. Poora token kabhi wapas nahi dikhta (safe).
Jahan test sends jaayenge. Number daala = test mode ON, khaali kiya = normal delivery. (Alag toggle ab nahi hai.)
⚠️ Interim test mode ON hai (number set hai) — har "Send on WhatsApp" is test number pe jaayega, students ko nahi. Normal delivery ke liye ye field clear kar de.
Kya badla

❌ Pehle (0097)

  • Token (UI se)
  • Interim number
  • Interim mode ka toggle (extra cheez — confuse kar rahi thi)
  • Sender number sirf .env me → badalna ho to restart

✅ Ab

  • Sender number (ab DB se, UI editable)
  • Token (UI se)
  • Interim number
  • Toggle hata diya → number = switch (set = ON, clear = OFF)
  • Teeno DB se → koi restart nahi
Ab dikhega + test hoga — steps
  1. Terminal me: docker compose up --build — naya code chadhega + migration 0025 khud apply hoga.
  2. Browser: sign in as platform admin → nav me WhatsApp.
  3. Sender number = tera Meta phone-number ID (API Setup se).
  4. Token = ek fresh token paste kar (abhi wala expire ho chuka hai). Best: permanent system-user token (phir kabhi expire nahi).
  5. Interim number = 919306229596 → Save.
  6. Kisi student pe Send on WhatsApp → intro text + asli photos us number pe aayenge (24h window khula hona chahiye).
