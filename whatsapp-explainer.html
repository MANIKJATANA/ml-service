5 things to understand (the confusing bits, simply)

1. Test number vs real number. Right now you're on Meta's free test number (+1 555…). It can only send to a few numbers you approve. To message real parents, you'll add your own business number later.
2. Two ways to send.
• Template = a pre-approved message format. Needed to message someone who has not messaged you first (i.e. real parents). For photos this needs an "image template" — not made yet.
• Free-form = any message/photo, but ONLY works for 24 hours after the person messages you. (Today's image test used this — it worked because you had messaged the test number.)
3. The 24-hour window. After someone WhatsApps your business number, you can send them anything freely for 24 hours. After that, only templates.
4. The temporary token. Meta's test token expires ~daily — that's the whole reason we're adding the "edit token on screen" feature.
5. Opt-in. The app only sends to a student marked "opted in" with a number on file (for real sends).
