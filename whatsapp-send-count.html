💬 WhatsApp send count — for costing

Har baar jab koi photo WhatsApp par jaati hai, wo save ho jaati hai. Ab hum wo count dikha rahe hain — per photo aur per school — taaki costing nikalna aasan ho. Har bheji hui image = ek message = ek cost unit.

Rule Kya count hota hai

Ek photo jitni baar actually bheji gayi, utna count. Agar ek hi photo me 2 log hain aur dono ko bheji → 2. Wahi photo 4 baar bheji → 4.

Data Ye pehle se save hai

Har send ki ek row pehle se ek log table me likhi jaati thi (kis school, kaunsi photo, status). Hum sirf us log ki status = "sent" rows gin rahe hain — koi nayi storage nahi, koi migration nahi. Recipient ka phone number kabhi save nahi hota (privacy-safe).

TL;DR Ek nazar me

  1. Har sent image = 1 message = 1 cost unit (fail/skip count nahi hote).
